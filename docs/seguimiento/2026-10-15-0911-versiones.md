## Avisos de seguridad y soporte que afectan la elección inicial

- Node anunció correcciones para 22.x/24.x/26.x para el 21/10/2026 o poco después; severidad máxima anunciada HIGH. Es anuncio, no parches ya publicados ni identificadores de futuras versiones confirmados. Revisar la siguiente publicación antes de cerrar imagen de construcción. [Aviso oficial](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases).
- Oracle indica próximo CPU el 20/10/2026 para la referencia JDK 25.0.4.1. No se inventa número de parche futuro. Su roadmap indica cambio de condiciones para actualizaciones de Oracle JDK 21 desde el CPU de octubre; esto no equivale a fin de soporte de Java 21 ni aplica automáticamente a otros distribuidores. Java 25 tiene soporte Premier Oracle hasta septiembre de 2030 y Extended hasta septiembre de 2033, bajo condiciones comerciales. [Notas JDK 25](https://www.oracle.com/java/technologies/javase/25all-relnotes.html), [roadmap Oracle](https://www.oracle.com/java/technologies/java-se-support-roadmap.html).
- Spring Security 7.1.1 corrige CVE-2026-41707 (repetición de prueba DPoP) y CVE-2026-47841 (WebAuthn con verificación requerida y sesiones distribuidas). Son avisos de agosto, no vulnerabilidades nuevas descubiertas hoy. Sin aplicación instalada ni funciones respectivas confirmadas, no se declara afectación. [DPoP](https://spring.io/security/cve-2026-41707/), [WebAuthn](https://spring.io/security/cve-2026-47841/).
- PostgreSQL 18.6 ya incorpora correcciones publicadas en su índice, incluida CVE-2026-14666 sobre caché de seguridad por fila y cambios de rol. Relevante al diseño RLS; sin parche posterior observado. Mantener pruebas con rol real y pool. [Índice oficial](https://www.postgresql.org/support/security/).
- Angular 22: soporte activo hasta junio de 2027 y LTS hasta junio de 2028 según calendario orientativo. Angular 20 termina LTS el 28/11/2026; no es la rama propuesta para este producto. [Calendario Angular](https://angular.dev/reference/releases).
- Calendario Node: rama 24 termina soporte el 30/04/2028 y entra en mantenimiento el 20/10/2026; rama 22 termina el 30/04/2027. Rama 26 entra en LTS el 28/10/2026 según planificación, aún Current a esta revisión. [Calendario del proyecto](https://raw.githubusercontent.com/nodejs/Release/main/schedule.json).

## Impacto, pruebas y reversión propuestos

1. Angular 22.2.3: sustituir la referencia candidata 22.2.2 al especificar la base, previa comprobación de CLI, TypeScript y Node. Cuando exista frontend, instalar desde lockfile reproducible, compilar producción y probar login/retorno Google, permisos por ruta/API, formularios, consultas y navegación. Reversión: restaurar manifiestos/lockfile y artefacto anterior; sin cambio de esquema por este parche. No reintroducir una versión vulnerable si el hallazgo se confirma aplicable: preferir corrección hacia adelante o deshabilitar el flujo afectado.
2. Node: rama 24 LTS como propuesta inicial; revalidar avisos del 21/10. Probar instalación limpia, build, tests y proceso de desarrollo; SSR solo si se adopta. Reversión: imagen/runtime y lockfile anteriores verificados; no cambiar la base de datos. Un frontend estático en el VPS no requiere por sí solo un servidor Node en producción.
3. Java/Spring: evaluar JDK 25 y Boot 4.1.1 con Security gestionada; revisar CPU del 20/10 antes de fijar build. Probar arranque, login OIDC, sesión/CSRF, revocación, representación, JDBC/RLS y tareas. Reversión: restaurar JDK/imagen y JAR compatibles; mantener esquema sin cambios en esta validación. Si una futura actualización incluye migraciones, exigir plan de datos separado.
4. PostgreSQL: no se propone actualización sobre 18.6 hoy. Al cambiar patch, revisar notas, disponer de copia/restauración comprobada y probar RLS, reutilización del pool tras rollback, capacidad concurrente y numeración. No considerar bajar binarios una reversión universal ni aplicar ese procedimiento a versiones mayores.

Ninguna de estas pruebas se ejecutó: todavía no existe aplicación. Pendientes de decisión: distribuidor JDK, parche tras próximos avisos, conjunto Angular/CLI/Node compatible y fechas de soporte Spring verificables.
